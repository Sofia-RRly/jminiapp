# Voting App — JMiniApp Example

This project is an example application built using the **JMiniApp** framework.  
It implements a flexible voting system that allows the user to manage candidates and votes.

---

## Features:

| Feature | Description |
|---|---|
| Add candidates | Register new candidates dynamically |
| Remove candidates | Delete a specific candidate by ID |
| Cast votes | Vote for any registered candidate |
| Remove votes | Undo a vote if the candidate has at least one |
| Total vote count | Shows the total number of votes in the session |
| Percentage calculation | Shows distribution of votes for each candidate |
| Reset system | Restores initial state with 3 default candidates |
